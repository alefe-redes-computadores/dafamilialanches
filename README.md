# 🍔 Da Família Lanches  

Site oficial da **Da Família Lanches (DFL)** — uma lanchonete mineira que combina sabor, qualidade e alegria em cada lanche.  
Feito com ❤️ e muito sabor, direto de Minas Gerais

---

## 🌐 Acesse o site  
👉 [https://dafamilialanches.vercel.app](https://dafamilialanches.vercel.app)

---

## ✨ Funcionalidades  

- 🖼️ Interface moderna e visual apetitoso  
- 📱 Layout totalmente responsivo (funciona em qualquer dispositivo)  
- 🍟 Seções dedicadas a **burgers**, **hot dogs**, **combos** e **promoções**  
- 📞 Acesso rápido via **WhatsApp** e **iFood**  
- ⚡ Carregamento otimizado e desempenho aprimorado  

---

## 🔧 Tecnologias utilizadas  

| Tecnologia | Uso principal |
|-------------|----------------|
| 🧩 **HTML5** | Estrutura do site |
| 🎨 **CSS3** | Estilos, layout e responsividade |
| ⚙️ **JavaScript** | Interações, animações e lógica dinâmica |

---

## 🚀 Como acessar localmente  

Se quiser rodar o site no seu computador:

1. Faça o download do repositório (**Code → Download ZIP**)  
2. Extraia os arquivos  
3. Abra o arquivo `index.html` no navegador
